Bash:Various Ways to Sort a String or Array

In this tale, I list various ways I’ve sorted the words in a string or the elements of an array. I’m very forgetful so I’m putting my notes for this sort of stuff in a publicly accessible place where I won’t forget where I put it. If anyone reads this and has any alternate methods, please post in the comments.
Declare a string of words to be sorted:
$ # Sort requires each word on a separate line
$ # xargs reassembles the one line string.
$ declare string="zebra aardvark yaml cat brontosaurus snake octopus lion tiger bear"
The sort command requires words to be separated by \n .
Method 1: Print each word followed by a newline, pipe output to sort, then xargs to reassemble lines to words.
$ for word in ${string}; do echo ${word}; done | sort | xargs
aardvark bear brontosaurus cat lion octopus snake tiger yaml zebra
Method 2: use sed rather than a for loop and multiple calls to echo for substituting \n for spaces
$ declare string="zebra aardvark yaml cat brontosaurus snake octopus lion tiger bear"
$ echo "${string}" | sed 's/ /\n/g' | sort | xargs
aardvark bear brontosaurus cat lion octopus snake tiger yaml zebra
Method 3: use bash to perform the substitutions.
$ declare string="zebra aardvark yaml cat brontosaurus snake octopus lion tiger bear"
$ # $'\n' is an ansi-c style string which is required to insert escape sequences.
$ echo "${string// /$'\n'}" | sort | xargs
aardvark bear brontosaurus cat lion octopus snake tiger yaml zebra
Method 4: use mapfile
$ declare string="zebra aardvark yaml cat brontosaurus snake octopus lion tiger bear"
$ mapfile < <( echo "${string// /$'\n'}" | sort )
$ echo ${MAPFILE[@]} 
aardvark bear brontosaurus cat lion octopus snake tiger yaml zebra
How about for arrays?
$ declare -a animals=( zebra aardvark yaml cat brontosaurus snake octopus lion tiger bear )
$ declare string="${animals[@]}"
$ # $'\n' is an ansi-c style string which is required to insert escape sequences.
$ # mapfile reads the output of the process substitution into an array.
$ mapfile -t animals < <( string="${animals[@]}"; echo ${string// /$'\n'} | sort | xargs; )
$ echo "${animals[@]}
aardvark bear brontosaurus cat lion octopus snake tiger yaml zebra
I could also use a command substitution, a here string, and the features of bash parameter expansion rather than using echo and a pipe to provide the input to the sort command.
$ declare string="zebra aardvark yaml cat brontosaurus snake octopus lion tiger bear"
$ # $'\n' is an ansi-c style string which is required to insert escape sequences.
$ # mapfile reads the output of the process substitution into an array.
$ mapfile -t animals < <( sort <<< "${string// /$'\n'}" )
$ string="${animals[@]}"
$ echo "${string}"
aardvark bear brontosaurus cat lion octopus snake tiger yaml zebra
$ # which is equivalent to
$ string="zebra aardvark yaml cat brontosaurus snake octopus lion tiger bear" 
$ string=$( sort <<< "${string// /$'\n'}" )
$ string="${string//$'\n'/ }"
$ echo "${string}"
aardvark bear brontosaurus cat lion octopus snake tiger yaml zebra
As a function:
function stringlib_sort_words {
  local -n _slswp=${1:?"${FUNCNAME}:${LINENO}:\${1} must be an reference to the function parameters."}
  if [[ -n ${_slswp[string]} ]]; then local _strin=${_slswp[string]}; else echo "${FUNCNAME}:${LINENO}:params[string] undefined"; return 1; fi
  local _strout=$( sort <<< "${_strin// /$'\n'}" )
  _strout="${_strout//$'\n'/ }"
  _slswp[string]="${_strout}"
}
