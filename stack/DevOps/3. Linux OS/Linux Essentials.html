Topic 01 Boot process

Boot process

From power-on to shell: firmware → bootloader → kernel → init/systemd → login.

From power-on to a login prompt: Firmware → Bootloader → Kernel & initramfs → PID 1 (systemd) → Targets/services.

Flow & components

  • Firmware (BIOS/UEFI) initializes hardware, selects a boot device.
  • Bootloader (e.g., GRUB, systemd-boot) loads the kernel and optional initramfs.
  • Kernel sets up memory, devices, mounts root FS (or asks initramfs to), then executes PID 1.
  • PID 1 is usually systemd; it starts targets and services in parallel with dependencies.
Tip: UEFI systems often have an EFI System Partition (ESP) mounted at /boot/efi.

Useful commands

# What happened this boot?
journalctl -b --no-pager | less
# Kernel messages
sudo dmesg --color=always | less -R
# Show default target (like runlevel)
systemctl get-default
# List failed services
systemctl --failed
# On UEFI: list boot entries
sudo efibootmgr
# Regenerate GRUB menu (Debian/Ubuntu)
sudo update-grub
# Regenerate initramfs (Debian/Ubuntu)
sudo update-initramfs -u
Note: Commands to rebuild GRUB/initramfs differ by distro (grub2-mkconfig, dracut, etc.). Check your distro docs.

Topic 03 Reading from files

Reading from files

Peek at files safely: cat for quick dumps, less/head/tail for paged or partial views.

Viewing

cat file.txt                    # small files
less -S file.txt                # pager; -S no wrap
head -n 20 file.txt             # first N lines
tail -n 50 file.txt             # last N lines
tail -f /var/log/syslog         # follow new lines
nl -ba file.txt                 # add line numbers
awk 'NR==42' file.txt           # show line 42

Extracting

# Columns and fields
cut -d: -f1 /etc/passwd         # first field by ':'
awk -F, '{print $2}' data.csv   # 2nd column of CSV
awk '/ERROR/' app.log | wc -l   # count ERROR lines

# Patterns
grep -n "^root" /etc/passwd     # line numbers
rg -n "TODO" -S .               # ripgrep (if installed)

# Bytes / hex
od -An -tx1 -N 16 file.bin      # first 16 bytes hex
Topic 04 Using sed

Using sed to edit files

Change text files in-place; learn save/quit, search/replace, and basic motions.

Substitutions

# Basic: replace foo with bar (print to stdout)
sed 's/foo/bar/' file
# Global per line; case-insensitive
sed 's/foo/bar/gi' file
# In-place edit with backup
sed -i.bak 's/8080/9090/g' app.conf
# Use a different delimiter for paths
sed -i 's#/var/www#/srv/http#g' conf

Ranges & deletes

# Delete lines 5-10
sed '5,10d' file
# Delete lines matching pattern
sed '/^#/d' file            # drop comments
# Only operate on matched lines
sed '/^server/ s/80/443/' nginx.conf

Insert/append & capture groups

# Insert line before matches
sed '/\[Service\]/i Environment=FOO=1' service.ini
# Append after matches
sed '/pattern/a New line here' file
# Capture and reuse (\1)
echo "name: Alice" | sed -E 's/name: (.*)/user=\1/'
Safety: Always keep a backup (-i.bak) or use version control when editing configs.

Topic 06 Finding files

Finding files

Locate things: find for filenames/metadata; grep/rg for text patterns.

find(1)

# By name/type
find . -type f -name "*.log"
find /var -maxdepth 2 -type d -iname "*nginx*"
# By time/size/owner
find /tmp -type f -mtime +7 -delete
find . -type f -size +100M -print
find / -user alice -perm -u+s 2>/dev/null
# Safe exec (-print0 with xargs -0)
find . -type f -print0 | xargs -0 grep -n "ERROR"

locate(1)

# Very fast DB-backed search
sudo updatedb            # update index (periodic via cron normally)
locate sshd_config
locate -i --regex '.*\.(jpg|png)$'
Tip: Consider fd or ripgrep for blazing-fast developer workflows if available.
Topic 07 Pipes & redirection

Piping and redirection

Wire commands together: | chains stdout, > overwrites, >> appends, 2> redirects errors.

# Stdout & stderr
cmd > out.txt            # stdout only
cmd >> out.txt           # append
cmd 2> err.txt           # stderr only
cmd > all.txt 2>&1       # both to same file

# Pipes
dmesg | grep -i usb | less

# tee: write to file AND stdout
make 2>&1 | tee build.log | less -R
# Here-docs & process substitution
cat <<'EOF' > script.sh
#!/usr/bin/env bash
echo "Hello"
EOF
chmod +x script.sh

# Feed output of a cmd as a file-like input
diff <(sort a.txt) <(sort b.txt)
Topic 08 Archiving

Archiving files

Variables & PATH; export and persist via shell rc files; subshells inherit their env.

tar + compression

# Create gz archive
 tar -czf site.tar.gz site/
# List contents
 tar -tf site.tar.gz | less
# Extract into ./dest
 mkdir -p dest && tar -xzf site.tar.gz -C dest
# Exclude patterns
 tar -czf src.tar.gz src/ --exclude-vcs --exclude='*.log'
Compression choices: gzip (fast), bzip2 (smaller), xz/zstd (modern; try -I zstd).

zip

zip -r project.zip project/
unzip -l project.zip   # list
unzip project.zip -d ./here
Topic 09 Permissions

Working with file permissions

Access model: user/group/other with r=4, w=2, x=1; change with chmod/chown/chgrp.

Basics

ls -l                  # e.g. -rwxr-x--- 1 alice dev 1K Sep 1 file
chmod u+x script.sh    # add execute for user
chmod g-w,o-r file     # remove specific bits
chmod 640 file         # numeric (u=rwx=7,g=4,o=0)
chown bob:dev file     # change owner & group
chgrp dev file         # change group only
Modes: r=4, w=2, x=1 → sum per class (u/g/o). Dirs need x to traverse.

Advanced

# Special bits
chmod 4755 prog    # setuid
chmod 2755 dir     # setgid (new files get group)
chmod 1777 /tmp    # sticky (only owner can delete)

# Default perms via umask
umask              # show (e.g., 0022)
# ACLs (if supported)
setfacl -m u:alice:rwx project/
getfacl project/

Topic 12 Crontab

Crontab (scheduled tasks)

Run things later or repeatedly: crontab for periodic tasks; systemd timers as modern alternative.

Per-user crontab

crontab -e             # edit your crontab
crontab -l             # list entries
# Fields: min hour dom month dow  (use * as wildcard)
# Example: run backup at 02:30 daily
30 2 * * * /usr/local/bin/backup.sh >> /var/log/backup.log 2>&1

Special strings & env

# Run at boot
@reboot /usr/local/bin/startup
# Weekly at 05:00
@weekly /path/job.sh
# Environment inside crontab
SHELL=/bin/bash
PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin
MAILTO=you@example.com
System cron: /etc/crontab, /etc/cron.d/, /etc/cron.daily… On some systems, systemd timers replace cron for new services.
Topic 13 Bash scripting

Bash scripting

Talk to other machines: inspect links/ports; SSH for remote shells; curl for HTTP APIs.

Skeleton & safety

#!/usr/bin/env bash
set -Eeuo pipefail
IFS=$'\n\t'

log(){ printf '[%s] %s\n' "$(date +%T)" "$*"; }
trap 'log "Error on line $LINENO"' ERR

: "${1?Usage: $0 NAME}"   # require arg NAME
name=$1

log "Hello, $name"

Idioms

# Variables & arrays
foo="value"; readonly CONST=42
arr=(one two three)
for x in "${arr[@]}"; do echo "$x"; done

# Conditionals & tests
if [[ -f /etc/os-release ]]; then source /etc/os-release; fi
[[ -n ${VAR:-} ]] || echo "VAR is empty"

# getopts
while getopts ":vho:" opt; do
  case $opt in
    v) verbose=1;;
    o) out=$OPTARG;;
    h) echo "help"; exit 0;;
    *) echo "bad option"; exit 2;;
  esac
done

Topic 15 Services

Managing services (systemd)

Manage long‑running services: systemctl start/stop/status, enable at boot, inspect unit files.

# Basic lifecycle
sudo systemctl status nginx
sudo systemctl start nginx
sudo systemctl stop nginx
sudo systemctl restart nginx
sudo systemctl enable --now nginx   # start at boot

# Logs
journalctl -u nginx --since "1 hour ago"
# Service discovery
systemctl list-units --type=service --state=running
# Override (drop-in) configuration
sudo systemctl edit nginx
# Default target (boot state)
systemctl get-default
# Change target (like runlevel)
sudo systemctl set-default multi-user.target
Legacy: Older distros use SysVinit (service, chkconfig). Prefer systemd on modern systems.

Topic 17 Login scripts

Managing login scripts (shell init)

Where events live: /var/log and journalctl; follow with -f, filter by unit/time/priority.

Files & order (Bash)

  • Login shells read /etc/profile, then the first of ~/.bash_profile, ~/.bash_login, or ~/.profile.
  • Interactive non-login shells read ~/.bashrc.
  • On logout, ~/.bash_logout runs.
Put aliases/functions in ~/.bashrc and source it from ~/.bash_profile:
[[ -f ~/.bashrc ]] && . ~/.bashrc

Examples

# ~/.bashrc
export EDITOR=vim
export PATH="$HOME/bin:$PATH"
# Safer rm
alias rm='rm -i'
# Prompt with git branch
PS1='\u@\h:\w$(git branch --show-current 2>/dev/null | sed "s/.*/ (\0)/")$ '

Topic 20 Sudoers

Sudoers file

Accounts & roles: useradd/usermod; groups for access; sudo for least‑privilege elevation.

Edit safely

# ALWAYS use visudo (syntax check)
sudo visudo
# Or add a dedicated drop-in file
sudo visudo -f /etc/sudoers.d/90-admins
Do not edit /etc/sudoers with a normal editor — a syntax error can lock you out.

Examples

# Allow members of 'sudo' to do anything (typical)
%sudo   ALL=(ALL:ALL) ALL
# Passwordless for specific cmd
alice  ALL=(root) NOPASSWD: /usr/sbin/systemctl restart nginx
# Set secure PATH for sudo
Defaults secure_path="/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"
Group names are prefixed with %. Use the visudo includedir (e.g., /etc/sudoers.d) for modular rules.
